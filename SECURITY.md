# Security Policy

## Supported Versions

Only the latest commit on the `main` branch is supported with security updates.

| Branch | Supported          |
| ------ | ------------------ |
| main   | :white_check_mark: |
| other  | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/mtsarac/portfolio-site/security/advisories/new).

Do not open a public issue for a suspected vulnerability.

Include: affected URLs or files, steps to reproduce, and the potential impact.
You will receive an initial response within 7 days.
